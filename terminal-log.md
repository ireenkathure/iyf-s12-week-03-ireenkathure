# Terminal Log - Week 03 - Ireen Kathure

## Navigation & Files
- `pwd` - Showed my current directory
- `ls -la` - Listed all files including hidden ones
- `mkdir my-awesome-project` - Created a new project folder
- `cd my-awesome-project` - Moved into the folder
- `touch index.html` - Created an empty file
- `cat index.html` - Showed file content

## Script
- `chmod +x new-project.sh` - Made the script executable
- `./new-project.sh` - Ran the script, it created src/docs/tests folders

## Git
- `git status` - Checked which files were changed
- `git add .` - Staged files for commit
- `git commit -m "Add: gitignore configuration"` - Saved gitignore
- `git branch feature/readme` - Created a feature branch
- `git checkout feature/readme` - Switched to that branch
- `git merge feature/readme` - Merged branch back to main
- `git branch -d feature/readme` - Deleted the branch after merge
- `git push origin main` - Pushed to GitHub
